# Bot detection — решение

Классификация кук (человек/бот) по поведенческим событиям. Метрика — Precision при Recall ≥ 0.70.

## Итог

| | P@R0.7 (CV) | ROC-AUC (CV) |
|---|---|---|
|  изначальная константа | 0.10 | — |
| **решение (ансамбль)** | **0.72** | **0.92** |


## Как запустить

```bash
python -m venv .venv && source .venv/bin/activate 
pip install -r requirements.txt
```

Дальше открыть `research.ipynb` в Jupyter/JupyterLab/VS Code и выполнить все ячейки сверху
вниз

Ноутбук сам подбирает гиперпараметры и кэширует
попытки в `hpo_log.csv`.
Отдельно подбор гиперпараметров
```bash
python hpo_search.py --family lightgbm --n_iter 30
python hpo_search.py --family catboost --n_iter 30
```

## Структура репозитория

- `research.ipynb` — основной ноутбук исследования
- `core.py` — общие функции (признаки, CV, метрика), используются и ноутбуком
- `hpo_search.py` — подбор гиперпараметров с сохранением в csv яайл
- `metric.py` — target метрика
- `hpo_log.csv` — все накопленные комбинации
- `submission.csv` — финальные предсказания для `data/test.csv`.

## Подход

**Признаки** (раздел 4 ноутбука, 46 штук) — только по событиям внутри окна наблюдения
(`window_start_ts <= event_ts < window_end_ts`,:
- паузы между событиями и их распределение (`gap_*`, `burstiness`, `same_gap_frac`);
- энтропии (час/категория/событие) — разнообразие поведения;
- UA-эвристики (`okhttp`/`headless`/бот-слова в user agent);
- вовлечённость (избранное, сообщения, логин);
- **движение мыши** — скорость и "прямолинейность" траектории по `pointer_x`/`pointer_y`

- ** признаки популярности** — средняя/максимальная "популярность" объявлений между
  куками и вероятность переходов между событиями (`P(след. событие | пред. событие)`) —
  пересчитываются отдельно на train-части каждой части времени
- `seller_type`/`item_location` — доли и разнообразие.

Категориальные поля (`item_category`, `platform`, `user_agent`) не идут в модель как есть —
преобразованы в числовые значения

**Валидация** — 5 прохождения по времени

**Что пробовали:**
- H1-H4 гипотезы (раздел 2/5/9) — проверены честно на CV, не на словах;
- HPO по 3 семействам бустингов (HistGB/LightGBM/CatBoost) через `hpo_search.py`
- N-модельный ансамбль с весами, отобранными полным перебором пар + случайным
  поиском по симплексу;
